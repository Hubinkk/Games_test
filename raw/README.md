- **原样保存，不改写。**截图只能转录文字的，注明"截图转录"；当时没有留下原文的，注明"转述"。
- 文件名：`日期-简短主题.md`。开头写来源、日期、谁分享的。

- 资料里的说法不一定对（比如营销数字）。我们的判断写在 `wiki/` 里，不写在这里。
- 每份资料被"吸收"后，在 `wiki/` 的相关页面里链接回来，并在下面的列表里打勾。
