# 仿真与工具

## 现在就能跑：MuJoCo（笔记本即可）
```
pip install mujoco
python -m mujoco.viewer --mjcf=sim/figure55_full.xml
cd sim && python full_demo.py
```
Ctrl + 鼠标右键拖动身体可以推它。只打开模型时没有平衡控制，要跑演示脚本才会站立、深蹲、走路。

## 强化学习（下一步，见 [[灵活度]]）
- **MuJoCo Playground**（DeepMind 开源）：Colab 免费 GPU，有人形机器人学走路的教程；可能要先把模型简化成"身体 + 腿"
- **Isaac Sim / Isaac Lab**（台式机 5070 Ti）：`docs/desktop-isaac.md`、`sim/figure55.urdf`、`sim/isaac/figure55_cfg.py` 已准备；能同时跑几千个分身
- 其他：Genesis（快、支持软体）、Newton（NVIDIA + DeepMind + 迪士尼）、Webots、LeRobot（实物数据）

## 待确认
台式机内存是否 ≥ 32 GB、系统是否 Windows 11 / Linux。

## 仓库里的主要脚本
`full_build.py` / `full_demo.py`（整体模型）、`agility.py`（灵活度）、`getup.py`（起身搜索）、`voice.py`（声道）、`tongue*.py`（舌头）、`hands*_demo.py`（打字）。
