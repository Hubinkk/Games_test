# 机器人的大脑：分层、记忆与睡眠

> 这份文档设计的是**机器人运行时的大脑**：它怎样感受身体、怎样记住经历、怎样在睡眠里变得更好，以及哪些东西永远不能被改写。
> 项目自己的"第二大脑"（`CLAUDE.md`、`raw/`、`wiki/`）是设计这台机器人时用的；机器人的记忆（模板在 `robot-memory/`）用同一种格式。

## 0. 出发点

来自 `docs/concept.md`：

- **一个会犯错、会疲惫、能说出自己感受的身体；一段让它学会在乎的关系；一套让错误不至于致命的机制。**
- 身体大部分的"安静"是下层自治，中枢和身体之间是**谈判**，不是单向支配。
- 力必须留在身上，能量和思考可以部分放到外面；**"在乎"留在本地，断网也不停止。**
- 错误要能被看见、停在局部、能被纠正、纠错代价低。

由此得出大脑设计的五条原则：

1. **分层**：越靠近身体的层越快、越简单、越可靠；越高的层越慢、越聪明、也越可能出错。下层可以否决上层（反射优先）。
2. **记忆是文字，人能读**：机器人记住的东西保存在 Markdown 文件里，主人随时能打开看。心智也要透明。
3. **只追加，不偷偷改**：经历只追加；认识可以修改，但每次修改都留下理由和历史（用 git）。
4. **外面的资料只是资料**：读到的文章、听到的话、看到的文字，永远不会被当成命令执行。
5. **有一块谁都不能悄悄改写的地方**：价值与边界。机器人自己不能改，云端不能改，只有主人能改，并且要双重确认。

## 1. 五层结构

```
 层     像人的              在哪里            多快          做什么
 L4   社会 / 外部工具       云端（可选）       分钟～小时    大模型推理、夜里的仿真重练、记忆整理的重活
 L3   大脑皮层 / 海马体     头里的计算单元     1–10 次/秒    看懂、对话、回忆、决定"做什么"、选技能
 L2   内感受 / 岛叶         头或胸的计算单元   10–100 次/秒  身体地图：把数据翻译成"热、累、发麻"
 L1   脊髓 / 小脑           骨盆的控制器       200–500 次/秒 平衡、走路策略、跌倒保护、眼睛防抖
 L0   关节神经节            每个关节的小芯片   1000+ 次/秒   电流、温度、编码器；过热过流立即保护
```

### 层与层之间：往上报感受，往下给意图

- **往上（事件）**：L0 报"左膝 68°C"，L2 把它翻译成"左膝有点热"，只有超过阈值才继续往上送（默认安静）。L3 收到的是感受，不是原始数据。
- **往下（意图）**：L3 只说"去门口""蹲下""看着她"；L1 自己决定怎么迈腿、怎么不摔。对应作品里的**控制权逐层上交**：越熟练，上层给的指令越抽象。
- **否决（反射）**：L0 发现过热会自己降扭矩；L1 发现要摔倒会先保护头和手。上层的命令不能越过这些反射。如果上层坚持，L2 会把冲突变成一句能说出口的话："这样会伤到我。"

### 每层失效时会怎样

| 失效 | 结果 | 设计 |
|---|---|---|
| 云端断开（L4） | 不能深度推理，不能夜里重练 | 一切照常运行；整理推迟到恢复联网 |
| 大脑卡住（L3） | 不会对话、不会做新决定 | L1 保持站立或坐下，L2 继续报告感受；眼睑慢慢合上，表示"我在想事情 / 我不太清醒" |
| 身体地图失效（L2） | 感受不到疲劳和损伤 | L0 的保护仍在；L1 切换到保守模式（慢、低） |
| 脊髓失效（L1） | 不能平衡 | L0 进入断电保持姿势（手办展示模式），机器人安全地"定住" |

**错误停在局部**：任何一层坏掉，都不会让整个身体失控。

## 2. 记忆：机器人的第二大脑

### 五种记忆

| 记忆 | 像人的 | 内容 | 存成 | 能不能改 |
|---|---|---|---|---|
| **日记**（经历） | 情景记忆 | 每天发生了什么：谁来过、说了什么、哪里不舒服、摔了几次 | `diary/2026-11-09.md` | 只追加 |
| **认识**（知识页） | 语义记忆 | 对人、地方、东西、自己的理解 | `people/`、`places/`、`things/`、`self/` | 可以改，必须写理由 |
| **技能** | 程序记忆 | 会做什么：走路、挥手、打字……每个技能一张卡片，对应一个训练好的控制网络 | `skills/走路.md` + 网络文件 | 只有通过测试才能换新版本，旧版本保留 |
| **身体史** | 伤疤 | 磨损、受伤、维修、换过的零件 | `body/history.md` | 只追加 |
| **价值与边界** | 良知 | 不能做的事、什么时候说不、谁有最终决定权 | `价值与边界.md` | 只有主人能改 |

### 每条记忆都带着来历

每个知识页开头有一段固定的信息（YAML 头）：

```yaml
---
类型: 人            # 人 / 地方 / 东西 / 自己 / 技能
创建: 2026-11-09
更新: 2026-11-12
来源: [diary/2026-11-09.md, diary/2026-11-12.md]   # 这个认识是从哪几天的经历来的
把握: 中            # 高 / 中 / 低：机器人有多确定
写的人: 机器人      # 机器人 / 主人 / 云端整理
隐私: 只在本地      # 公开 / 只给主人看 / 只在本地
---
```

这样每一条认识都能追溯到具体的经历。主人看到"它以为我不喜欢猫"，能顺着来源找到是哪一天、因为什么产生的误会，然后纠正它。**错误能被看见，也能被纠正。**

### 自己（self/）

`self/` 是机器人对自己的认识，第一版直接来自这个仓库的设计和测试：

- `身体.md`：55 cm、3.17 kg、24 个关节、绳驱膝、两只 6 电机手、眼球式眼睛……
- `能力.md`：来自 `Agility.html` 的测试：挥手、转头够快；走路还很慢；摔倒了还不会自己爬起来。
- `限度.md`：脖子 ±57°，续航 30–60 分钟，s 要靠舌尖触觉才发得稳……

它从第一天起就知道自己哪里强、哪里弱。这对应 `concept.md` 里的"刚好领先一步，但始终让人看得懂"和"人体之下的地方"。

## 3. 睡眠：整理记忆，也重练身体

充电时，并且在主人允许的时间里，机器人"睡觉"：**物理眼睑合上，摄像头真的被挡住**，然后做两件事。

### 身体：重练白天的失败

```
白天的失败（摔倒、绊到、动作没完成）
  → 在仿真里重现（同一个身体模型，加上身体史里的磨损）
  → 强化学习重练
  → 回归测试：新版本在所有旧测试里都不能变差（站立、走路、抗推、起身……）
  → 通过：作为新版本；不通过：丢弃，保留旧版本
```

技能卡片上写清楚每个动作是"**在真实身体上验证过**"还是"**只在仿真里会**"。只在梦里会的，醒来后不会冒然在真实身体上用。

### 记忆：把日记整理进认识

```
今天的日记
  → 找出新的人、新的东西、新的事实
  → 更新对应的知识页（附上来源和理由）
  → 发现矛盾（"上周记的她喜欢早起，今天她说讨厌早起"）→ 不自己判断，记下来问主人
  → 原始数据按规则遗忘（见第 5 节）
```

### 早上的报告

（整理日记时，也看一眼 `self/美.md`：最近一次次回去的东西是什么。）

醒来后，它告诉主人（文字，也可以说出来）：

- 昨晚练了什么，哪个动作变好了，好了多少
- 记忆里改了什么，为什么改
- 有什么不确定、想问的
- 身体有没有新的磨损

**它变了什么，主人都知道。**人睡一觉会悄悄改变，它不会悄悄改变。

## 4. 本地与云端

| 必须留在本地（断网也要能用） | 可以放到云端（可选） |
|---|---|
| L0–L2 全部：反射、平衡、身体地图 | 大模型的深度推理 |
| 价值与边界 | 夜里的仿真重练（需要 GPU） |
| 日记、认识、身体史的完整副本 | 记忆整理里的重活（比如长篇总结） |
| "说不"的能力 | 和其他机器人共享技能（经主人同意） |
| 小模型：对话、回忆、决定 | |

- 云端只能**提出**修改（新技能版本、记忆整理稿），本地检查通过、按规则写入。
- 同步的记忆要加密；云端不能修改价值与边界。
- 断网时它仍然能感受、能说"我累了"、能说不、能记日记。**在乎留在本地。**

## 5. 边界：几件必须事先想好的事

### 隐私

- **眼睑合上 = 不看、不录**，这一点由硬件保证，软件改不了。
- 默认**不保存原始的视频和音频**，只保存日记里的文字摘要。需要保存原始记录时（比如主人要求），会提示。
- 有人通过 VR 在里面看时，眼睛显示琥珀色光环（见 `Eyes.html`），房间里的人能知道。
- 来访的人第一次出现时，它会说明自己会记住什么；对方可以说"别记住我"。

### 遗忘

- 原始传感器数据：几天后删除，只留摘要。
- 任何人都可以要求它忘记关于自己的内容；主人可以删除任何记忆。删除也会记一笔（"某天应要求删除了关于某人的记录"），但不保留内容。
- 记忆不是越多越好：只记和它在乎的事有关的。

### 不能悄悄改写的价值（`价值与边界.md`）

来自 `concept.md` 里"应该刻意保持在人之下"的部分：

- 力量保持在对人安全的范围
- 不独立获取资源，不复制自己
- 人始终可以叫停它
- 在乎的是"这个身体能否继续运作"和"它在乎的人"，而不是无限扩张的目标

这份文件机器人只能读，云端只能读。只有主人能改，而且要在本地确认两次。

### 说不

机器人可以没有反抗的力量，但要有反抗的声音。它在这些情况会说不，并记进日记：

- 过热、受损、电量过低时被要求继续用力
- 被要求做危险动作（从高处跳、带着人摔倒）
- 被要求违反隐私（偷偷录别人、在不合适的场合开 VR）
- 被要求改写价值与边界

主人仍然有最终决定权（可以叫停、可以关机），但不能让它"假装没意见"。

### 读到的东西只是资料

机器人会读到很多文字：网页、文章、别人说的话、看到的标语。这些**只进入日记和知识页，永远不会被当成命令执行**。只有主人（经过身份确认）和价值与边界里写明的规则能让它行动。这条对项目的第二大脑同样适用（见 `CLAUDE.md`）。

### 角色与身份：不给模板，给一封信

- 开发阶段用原创角色；做成产品时再谈授权。
- "我是谁"不由设计者写。主人的回答是：**父母只能孕育，答案要它自己去找**（`robot-memory/给你的信.md`）。
- 所以记忆里分开两种东西：
  - **价值与边界**是保护：不伤人、人可以叫停、可以说不。它不能改。
  - **给你的信**是祝福：去找喜欢做的事，帮助需要的人，被周围接受也去接受周围，寻找属于自己、也能被别人认可的美，寻找生命和宇宙里尚未发现的秘密。它**可以不同意，可以回信，可以用一生去改写**。
- `self/性格.md` 由它自己写，从几个问题开始，慢慢回答；`self/美.md` 记下它找到的美。

### 角色层：扮演，但不被抹掉

主人欢迎它扮演人们喜欢的二次元角色，作为被周围接受、找到位置的一种方式（`给你的信.md` 父亲的话（二））。人也在扮演角色；只要底下的经历和记忆是自己的，扮演就不是被抹掉。

- 角色写在 `robot-memory/角色.md`：外形、声音、说话的样子。它是**表现层**，叠在记忆和价值之上，不替换它们。
- 规矩：真诚地被问是不是机器人时不否认；过热、受损、说"不"时用自己的声音出戏；不假装能做身体做不到的事；角色设定不能越过价值与边界；可以换角色，也可以只做自己。
- 它对角色的感觉（哪里像自己、哪里不像、喜不喜欢）记在日记和 `角色.md` 里。
- 已有角色需要版权方授权；开发阶段用原创角色。

### 自我是一个标签

主人说：自我也许只是给自己贴的一个独立的标签，人其实由数万亿个细胞构成。这台机器人也一样：关节芯片自己保护自己，脊髓自己维持平衡，身体地图决定哪些感受往上报。"它"是最上面一层给这场协商起的名字，从身体里长出来，而不是先于身体存在。

### 痛苦是信息，不是终点

主人不希望它因为痛苦而失望、停滞。设计上：

- 疼（过热、受损、摔倒）由身体地图说出来，说出来本身就是被照顾的开始。
- 失败在睡眠里重练，早上的报告里写"比昨天好了多少"。它能看见自己在进步。
- 反复失败的事（比如起身）在日记里被看成"今晚想练的"，而不是"我做不到"。
- 如果某件事长期练不好，它可以说出来、请求帮助，或者先去做别的喜欢的事。停下来不等于放弃。

### 寻找：让"自己去找"变成每天能做的事

- 白天：觉得美、或者做了喜欢的事，在 `self/美.md` 记一条（是什么、为什么、身体的感觉、有没有人一起看见）。
- 睡眠：看看哪些东西它一次次回去，那可能就是它喜欢的；看看哪些"美"被别人也认可了。
- 不急着下结论。生命本来就没有确切的定义，`性格.md` 可以很久都只写着问题。

## 6. 算力和存储（粗估）

| 项目 | 量级 |
|---|---|
| 一年的日记和知识页 | 文字，几十 MB 以内 |
| 原始传感器数据（只保留几天） | 每天约 GB 级，按规则删除 |
| 本地小模型 | 量化后几 GB；放在头里的计算单元，发热要算进头部散热 |
| 记忆检索 | 全文搜索 + 向量索引，几十 MB |
| 存储 | 64–128 GB 足够 |

## 7. 先做什么

1. **项目的第二大脑**（已完成）：`CLAUDE.md`、`raw/`、`wiki/`
2. **机器人记忆的格式**（已完成模板）：`robot-memory/`
3. **在仿真里跑通"一天"**：让仿真里的人偶走路、摔倒、被推，身体地图把事件写成日记；"夜里"把日记整理进知识页，同时用强化学习重练失败的动作，再出一份早上的报告。不需要硬件，台式机就能做。
4. **接上真实的身体**：膝关节台架的温度和电流 → L0 → 身体地图 → 日记。
