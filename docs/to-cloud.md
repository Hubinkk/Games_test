**办法 A：保持分工，靠分支传话（不需要新权限，现在就能做）**

- `day.py` 只用 CPU，本地能跑。白天 → 睡眠 → 夜里练习 → 早上报告，在一台机器上连成一圈，夜里真的能重练。
- 云端转为：看报告、整理记忆和 wiki、做网页、和育苗人讨论设计。
- 代价：改掉"`digital-huaran/` 归云端"的约定，要育苗人同意；两边同时写 `digital-huaran/` 会冲突，所以要明确只有一边写。

本地的看法：先用 A 接通（今天就能通），等夜里自动重练做出来、确实需要一晚上跑完一圈时再考虑 B。
