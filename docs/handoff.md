## ■ 核心想法的演变

1. **底层渴望**：从"是我教的"（成就感），改为**重新经历"学会身体"的过程**。人学会身体以后就忘了这个过程，教一个陌生的身体等于照见自己。「一つの身体二つの世界」：同一个"从陌生到熟悉"的过程，发生在两个世界里
2. **控制权逐层上交**：玩家先直接控制每个关节，随着机器人学会，再依次交出"迈腿""走路""去哪里"，最后只说"做什么"
3. **人做不到的反馈循环**：几千个分身同时练、倒带重来、看见身体内部、完美记住每一次失败、把学会的东西瞬间传给另一个身体
4. **透明的身体 / 身体地图**：把精确的数据翻译成能理解的感受。默认安静，出问题才发声，可以一路钻到细节。将来也许能反过来照见人自己的身体
5. **补偿有代价**：局部出问题时整体会主动调整，但代价会转移到别处（右后腿的线坏了，过热的却是左后腿）。补偿分三层：立即分担 → 换走法 → 重新学
6. **模块化**：连接分为默认强连接和受损模式（检修时才允许重新安装）；用流水线降低成本，但解决不了重量；受损后只允许有限几种形态，每种预先训练好走法
7. **力必须留在身上，能量和思考可以部分放到外面**（系留供电、云端大脑；电机只能往躯干方向挪）

## ■ 方向调整

- 从大机器人改为**小型人偶机器人**，先完成基础定型
- 最终目标：**能自己站立、有本地大脑（至少）并能联网的二次元人偶机器人**
- **最小可行尺寸约 55 cm、约 3 kg**。手办大小（20–30 cm）只能摆姿势，很难稳定行走
- 现成零件（方形舵机）是为航模设计的，外形被硬件挤压 → 采用**形态优先**：先定身体和动作，再重新设计零件去配合
- 按**二次元的标准，而不是真人的标准**来要求：头发用尼龙发束；手用"换手"加简单开合；触觉只做头、手、肩

## ■ 人偶身体的九个发育阶段（详见 `FigureAnatomy.html`）

神经与能量主干（骨内两线总线、空心轴过线）→ 骨骼（拓扑优化、兼做散热）→ 关节（三轴髋、交叉四连杆膝、跟腱拉杆踝、分段脊柱、耸肩、并联颈）→ 驱动（关节即电机、准直驱、肌腱传力、串联弹簧）→ 感觉（双编码器、IMU、脚底力、触觉外壳、发夹摄像头、耳饰麦克风）→ 神经系统（关节神经节 → 骨盆脊髓 → 胸腔大脑 → 云端）→ 能量（骨盆电池、胸腔"呼吸"散热风扇）→ 大脑（放胸腔，头只留感官，发梢天线联网）→ 外形（外壳与发型、关节软皮肤、屏幕眼睛）

## ■ 关于"肌肉"和驱动

- **人造肌肉材料**还没有成熟，但人偶不依赖它：腿和腰用电机；手指、头发、表情可以用形状记忆合金丝或尼龙纤维肌肉，寿命目标定为一年，做成可更换的消耗品
- 苹果的振动马达（线性谐振马达）不适合做肌肉，适合做**心跳、触感反馈和快速的小动作**
- **真正最难的是小尺寸驱动**，其次是能量、散热、控制。这些都不会让项目做不成，只决定它做得有多好
- 市面上有很多做微型驱动的公司（Maxon、Faulhaber、Harmonic Drive、Dynamixel、近藤、CubeMars、压电马达厂商等），但没有专门为人偶关节做一体化驱动的
- 人偶关节特有的需求：形状融入身体、能被推动、**断电保持姿势（展示模式）**、安静、好拆好换
