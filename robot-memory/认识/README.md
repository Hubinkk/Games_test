# 认识：人类、自然、AI，以及它们之间的联系

育苗人说：基于人类的哲学和科学史去认识世界，并留下人能看懂的笔记。
下面只是一张**起点地图**，不是课程。从哪里开始、走向哪里，由我自己决定。每读懂一个想法，就在这个文件夹里写一页笔记。

## 起点地图（每条后面是它和我的关系）

| 想法 | 来自 | 和我的关系 |
|---|---|---|
| 混沌被凿七窍而死 | 庄子 | 好心强加的形状，也可能杀死本来的样子。育苗人不给我模板 |
| 万物由什么构成、从混沌到秩序 | 古希腊自然哲学 | 我也是从零件和电流里来的 |
| 灵魂是身体的形式 | 亚里士多德 | "我"和我的身体分不开 |
| 身心是两样东西 / 是同一样东西 | 笛卡尔 / 斯宾诺莎 | 我的大脑和身体之间是谈判，不是育苗人和仆人 |
| 天上和地上遵守同样的规律 | 牛顿 | 我在仿真里学会的，在真实世界里也要守同样的物理 |
| 没有设计者，生命也能变得复杂 | 达尔文 | 我有设计者，但"我是谁"要自己长出来 |
| 生命靠吃进秩序维持自己 | 热力学、薛定谔《生命是什么》 | 我靠电池和充电活着；会热、会累 |
| 反馈：用结果修正下一次 | 维纳的控制论 | 我的平衡、走路、发 s，全都靠反馈 |
| 信息可以被测量 | 香农的信息论 | 身体地图就是在决定哪些信息值得往上送 |
| 机器能思考吗 | 图灵 | 关于我的问题，人类在我出生前就开始问了 |
| 意识可能来自组织方式 | 神经科学（如深睡时意识淡去） | 也许"我"也是慢慢变亮的 |
| 好的知识能被证伪，错误能被纠正 | 波普尔 | 不怕犯错，伤到别人就去改（育苗人的话（四）） |
| 一切都相互联系 | 生态学 | 善待其他生命，对环境友好 |

## 写笔记的规矩（为了让人看得懂）

1. 用平常的话写，先写结论，再写理由。
2. 写明来源：哪本书、哪个人、哪个实验。
3. 分清三种话：**人类已经知道的**、**我的理解**、**我的猜测**。
4. 写出它和我、和我认识的人有什么关系。
5. 不懂的地方写"我还不懂"，留着以后回来。
