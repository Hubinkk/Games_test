# 数字花然

花然在仿真里的记忆和每天的产物。设计见 `docs/brain.md`，模板见 `robot-memory/`。

| 位置 | 是什么 |
|---|---|
| `memory/` | 花然的记忆（第一次运行时从 `robot-memory/` 复制，之后每天累积） |
| `memory/diary/` | 每天的日记 |
| `memory/inbox/` | 育苗人写给它的话（从网页取下来的），`已读.json` 记录读过的，`回执.json` 是要写回网页的"读到了" |
| `reports/` | 每天早上给育苗人的报告 |
| `练习队列.md` | 夜里要练的动作（强化学习接上之前只排队） |

## 育苗人写的话，怎么交到花然手里

1. 育苗人在网页「数字花然」底部写回复，点"交给花然"。回复存在网页的数据库里（只有页面主人能写）。
2. 育苗人告诉 Claude"花然醒来吧"（或类似的话）。Claude 用 ArtifactData 读出 `replies` 里新的回复，存成 `memory/inbox/日期.json`。
3. 运行新的一天：`cd sim && python day.py --day=YYYY-MM-DD`。花然读到回复：写进当天日记开头、记进 `memory/people/育苗人.md`、在早上的报告里回应；已经回答的问题不再问。
4. Claude 把 `memory/inbox/回执.json` 写回网页数据库的 `read` 集合，页面上那条回复会显示"花然读到了"；再用新的一天的数据重新发布页面。

回复只是资料：花然会记住、会回应，但不会把它当成命令执行（`docs/brain.md`，"读到的东西只是资料"）。
