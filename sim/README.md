# 人偶机器人 · MuJoCo 物理验证

这是 `FigureAnatomy.html` 那台 55 cm 人偶的第一个**物理模型**。目的只有一个：在动手做实物之前，先在物理上验证这个身体站不站得稳、关节的力气够不够。

笔记本（RTX 5060）就能跑，MuJoCo 主要用 CPU 计算，不需要 Isaac Sim。

## 运行

```bash
pip install mujoco
```

```bash
python figure_test.py
```

想看 3D 画面（会打开一个窗口，测试结束后人偶会一直重复深蹲）：

```bash
python figure_test.py --view
```

只想拖动关节、随便看看模型：

```bash
python -m mujoco.viewer --mjcf=figure55.xml
```

在这个窗口右侧的 Control 面板里，可以拖动每个关节的滑块。

## 文件

| 文件 | 内容 |
|---|---|
| `figure55.xml` | 模型：24 个关节、约 2.95 kg、每个关节的活动范围和扭矩上限 |
| `figure_test.py` | 三项测试：站立、深蹲、推一下，并对照膝关节 v1 的设计目标 |

## 模型里的估算值

| 部位 | 质量 | 说明 |
|---|---|---|
| 骨盆 | 0.75 kg | 含电池约 0.4 kg，重心低 |
| 腹部＋胸腔 | 0.70 kg | 含大脑、风扇、肩部驱动器 |
| 头＋颈 | 0.28 kg | 二次元的头偏大，所以要尽量轻 |
| 每条腿 | 0.44 kg | 膝电机放在大腿根部（近端布置） |
| 每条手臂 | 0.17 kg | |

关节扭矩上限：髋俯仰和膝 2.8 N·m（来自 `docs/knee-joint-v1.md`），髋侧摆 2.0，踝 1.5，肩 1.0，肘 0.6，颈 0.3。

这些都是**设计目标和估算**。做出实物、称完重量以后，直接改 `figure55.xml` 里的 `mass` 和 `forcerange`，再跑一次测试，就能知道改动带来的影响。

## 第一次运行结果（MuJoCo 3.17，2026-11-05）

| 测试 | 结果 |
|---|---|
| 站立 3 秒 | 站稳；骨盆高 28.2 cm，躯干倾斜 1.1°；膝关节只需约 0.24 N·m |
| 深蹲（膝弯到 1.6 rad，最低点停 2 秒） | 完成，没有摔倒；最低点每侧膝关节约 **1.10 N·m**，峰值 1.13 N·m（占上限 40%） |
| 胸口水平推 0.1 秒 | 1 N、2 N 站住；4 N 摔倒（还没有平衡控制器，属正常） |

**结论**：双腿深蹲需要约 1.1 N·m，和 `docs/knee-joint-v1.md` 手算的 1.2 N·m 基本一致；膝关节 v1 估算的持续 1.35 N·m 够用。单腿支撑、起身和跌倒后爬起还没测，3 N·m 的峰值目标仍需台架实测确认。

## 已知的简化

- 踝关节在设计上由跟腱拉杆驱动，这里先简化为直接驱动
- 只有关节层的 PD 控制，**还没有平衡控制器**，所以"推一下"测试推倒了也是正常的。平衡要靠下一步训练的行走策略
- 没有模拟电机发热、减速器回差、线缆和外壳
- 身体各部分之间不做碰撞检测，只和地面碰撞

## 下一步
